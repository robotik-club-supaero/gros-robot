Merci de documenter votre code **au fur et à mesure** le plus possible !!
L'entièreté de la documentation et des choix techniques est sur le Drive dans le dossier Coupe 2027/Gros robot/ pour des facilités de formattage et d'utilisation.

Je compte sur tous les membres de l'info pour garder ce repo propre et faisant des commits réguliers. 

Pour développer une fonctionnalité du gros robot : 
1. Créer une nouvelle branche avec un nom clair.
2. Développer votre code de votre côté en essayant de faire un exemple de code MINIMAL. 
3. Quand la fonctionnalité est prête, l'intégrer au gros robot avec celui qui gère le code au global. 
4. Rajouter l'exemple de code MINIMAL pour le faire fonctionner dans le dossier fonctionnalités/

Le code complet du gros robot reste à la racine du dossier. 

Mettre le plus de commentaires possible dans le code, et surtout pas d'acronymes !!
